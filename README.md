#  House Price Prediction Using Linear Regression

This project focuses on predicting house prices using **Linear Regression**, a fundamental supervised machine learning algorithm. The goal is to understand the complete regression workflow, from data preprocessing to model evaluation.

---

##  Project Overview

House price prediction is a regression problem where the objective is to estimate property prices based on input features such as size, location, and other attributes.  
In this project, a **Linear Regression model** was trained and tested on a preprocessed dataset.

---

##  Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

---

##  Data Preprocessing

The dataset was fully preprocessed before modeling, including:
- Removal of duplicate records
- Handling missing values
- Train-test split

---

##  Machine Learning Model

### Linear Regression
- A baseline regression model
- Assumes a linear relationship between features and target variable
- Easy to interpret and efficient

---

##  Model Evaluation

Since this is a regression problem, the following metrics were used:

- **R² Score**
- **Mean Absolute Error (MAE)**
- **Root Mean Squared Error (RMSE)**

### Performance Results
- **Training R²:** 0.81  
- **Testing R²:** 0.85  

This indicates good generalization with minimal underfitting.

---

##  Conclusion

Linear Regression provided a strong baseline for house price prediction. The small difference between training and testing R² scores suggests that the model generalizes well to unseen data. Future improvements may involve using more advanced models to capture non-linear relationships.
